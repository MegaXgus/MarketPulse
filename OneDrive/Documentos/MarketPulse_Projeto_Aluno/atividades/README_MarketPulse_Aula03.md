# MarketPulse — Aula 03

## Tema
Problemas de design e antipadrões

## Situação do projeto
O MarketPulse contém decisões e artefatos legados que podem estar incompletos, inconsistentes ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. inspecionar o código legado e localizar evidências de alto acoplamento, baixa coesão, duplicação ou responsabilidades inadequadas;
2. produzir `docs/aula03-achados-tecnicos.md` citando arquivos/classes e evidências;
3. classificar cada achado como sintoma, causa provável ou consequência;
4. abrir ao menos uma Issue técnica priorizada para correção posterior.

## Dicas
- Nesta aula o foco é diagnosticar, não corrigir tudo.
- A existência de uma classe chamada `Factory`, `Adapter` ou `Facade` não prova que o padrão esteja correto.

## Evidências mínimas da entrega
- Issue identificada como `Aula 03`.
- Branch sugerida: `aula-03`.
- Commits com mensagens que expliquem mudanças relevantes.
- README/Markdown da entrega contendo **problema observado, alteração realizada e critério de aceitação**.
- PR ou registro equivalente permitindo revisão do grupo.

## Prazo operacional
O trabalho deve começar em sala. O limite de conclusão é o início da aula seguinte, salvo orientação diferente do professor.
