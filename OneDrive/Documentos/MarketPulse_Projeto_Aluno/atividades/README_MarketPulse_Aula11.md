# MarketPulse — Aula 11

## Tema
Modelo de domínio, componentes e conectores

## Situação do projeto
O MarketPulse contém decisões e artefatos legados que podem estar incompletos, inconsistentes ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. identificar conceitos de domínio a partir dos requisitos, evitando copiar diretamente nomes de classes existentes;
2. produzir cartões CRC ou registro equivalente para os conceitos centrais;
3. refinar o Modelo de Domínio e indicar responsabilidades/colaborações;
4. propor componentes, conectores e fronteiras coerentes com a arquitetura escolhida.

## Dicas
- `Investor`, `Order` e `Quote` do legado são pistas, não respostas definitivas.
- Diferenciar conceito de domínio de classe de infraestrutura.

## Evidências mínimas da entrega
- Issue identificada como `Aula 11`.
- Branch sugerida: `aula-11`.
- Commits com mensagens que expliquem mudanças relevantes.
- README/Markdown da entrega contendo **problema observado, alteração realizada e critério de aceitação**.
- PR ou registro equivalente permitindo revisão do grupo.

## Prazo operacional
O trabalho deve começar em sala. O limite de conclusão é o início da aula seguinte, salvo orientação diferente do professor.
