# MarketPulse — Aula 12

## Tema
UML, C4, sequência e Architecture as Code

## Situação do projeto
O MarketPulse contém decisões e artefatos legados que podem estar incompletos, inconsistentes ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. refinar as visões C4 de Contexto e Contêiner;
2. produzir UML de classes/componentes coerente com o modelo de domínio;
3. modelar em Diagrama de Sequência um cenário crítico, como envio de ordem até confirmação/rejeição;
4. versionar os arquivos-fonte dos diagramas em `docs/diagramas` e verificar consistência com o código.

## Dicas
- Escolher cenários em que responsabilidades e integrações sejam visíveis.
- O diagrama legado está propositalmente incompleto.

## Evidências mínimas da entrega
- Issue identificada como `Aula 12`.
- Branch sugerida: `aula-12`.
- Commits com mensagens que expliquem mudanças relevantes.
- README/Markdown da entrega contendo **problema observado, alteração realizada e critério de aceitação**.
- PR ou registro equivalente permitindo revisão do grupo.

## Prazo operacional
O trabalho deve começar em sala. O limite de conclusão é o início da aula seguinte, salvo orientação diferente do professor.
