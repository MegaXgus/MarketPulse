# MarketPulse — Aula 01

## Tema
Fundamentos e organização do repositório

## Situação do projeto
O MarketPulse contém decisões e artefatos legados que podem estar incompletos, inconsistentes ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. identificar no repositório exemplos de requisito, design, arquitetura e implementação e registrar as diferenças em `docs/aula01-fundamentos.md`;
2. revisar a estrutura de pastas e propor organização para acompanhar a evolução semestral;
3. registrar os papéis do grupo e a responsabilidade inicial de cada integrante;
4. criar uma Issue da Aula 01 e vinculá-la à entrega.

## Dicas
- Não é necessário corrigir o código nesta aula.
- Toda mudança estrutural deve ser justificada.

## Evidências mínimas da entrega
- Issue identificada como `Aula 01`.
- Branch sugerida: `aula-01`.
- Commits com mensagens que expliquem mudanças relevantes.
- README/Markdown da entrega contendo **problema observado, alteração realizada e critério de aceitação**.
- PR ou registro equivalente permitindo revisão do grupo.

## Prazo operacional
O trabalho deve começar em sala. O limite de conclusão é o início da aula seguinte, salvo orientação diferente do professor.
