# MarketPulse — Aula 07

## Tema
Estilos arquiteturais e trade-offs

## Situação do projeto
O MarketPulse contém decisões e artefatos legados que podem estar incompletos, inconsistentes ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. questionar a afirmação de `docs/arquitetura_inicial.md` de que o sistema deve usar microsserviços;
2. comparar monólito, camadas, microsserviços e orientação a eventos para o cenário do MarketPulse;
3. produzir matriz de trade-offs ligada aos requisitos da Aula 06;
4. substituir ou revisar `ADR-0001` com decisão arquitetural justificável.

## Dicas
- Não existe estilo melhor em qualquer contexto.
- Custos operacionais e consistência de ordens também entram no trade-off.

## Evidências mínimas da entrega
- Issue identificada como `Aula 07`.
- Branch sugerida: `aula-07`.
- Commits com mensagens que expliquem mudanças relevantes.
- README/Markdown da entrega contendo **problema observado, alteração realizada e critério de aceitação**.
- PR ou registro equivalente permitindo revisão do grupo.

## Prazo operacional
O trabalho deve começar em sala. O limite de conclusão é o início da aula seguinte, salvo orientação diferente do professor.
