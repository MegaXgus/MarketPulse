# MarketPulse — Aula 17

## Tema
Avaliação N2 e consolidação da segunda etapa

## Situação do projeto
O MarketPulse contém decisões e artefatos legados que podem estar incompletos, inconsistentes ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. organizar as evidências práticas das Aulas 11 a 16 em um índice auditável;
2. verificar se os seis padrões exigidos possuem problema associado, código, modelo e ADR;
3. consolidar pendências técnicas sem apagar o histórico de decisões;
4. preparar o repositório para integração com a etapa final/PI conforme orientação institucional.

## Dicas
- Quantidade de padrões não substitui adequação.
- Não reescrever o histórico Git para esconder tentativas ou correções relevantes.

## Evidências mínimas da entrega
- Issue identificada como `Aula 17`.
- Branch sugerida: `aula-17`.
- Commits com mensagens que expliquem mudanças relevantes.
- README/Markdown da entrega contendo **problema observado, alteração realizada e critério de aceitação**.

## Prazo operacional
O trabalho deve começar em sala. O limite de conclusão é o início da aula seguinte, salvo orientação diferente do professor.
