# Requisitos iniciais
- RF01 — O sistema deve permitir investir em ativos.
- RF02 — O sistema deve mostrar cotações rapidamente.
- RF03 — O sistema deve avisar o usuário quando for necessário.
- RNF01 — O sistema deve ser seguro.
- RNF02 — O sistema deve ser rápido.
- RNF03 — O sistema deve estar sempre disponível.

Os requisitos foram herdados de uma versão preliminar e ainda não possuem critérios de aceitação nem rastreabilidade.
